# cancho-stats

Statistics on tabular data as a command line an agent can read: summaries, correlations, hypothesis tests, confidence intervals, resampling, distribution fits and
regression with standard errors and p-values. Exact sums rounded once, the same bytes at any thread count, refusals that name their rule and a repair.

**Status: design phase. No code exists.** The design is [docs/design.md](docs/design.md); the milestones are the issues of this repository. It sits above
[cancho-table](https://github.com/alpibrusl/cancho-table) (reading and exact aggregates) and uses the numeric modules of
[cancho-ml](https://github.com/alpibrusl/cancho-ml) as pinned stores (cancho-ml#46).
